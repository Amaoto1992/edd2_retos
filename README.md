# Estructuras de Datos II - Retos

Universidad Autónoma de Occidente · Danny Castrillón

Retos del curso hechos en Flutter. Cada reto está en su propia rama y todas
se fusionan en `main`.

## Ramas

| Rama | Reto | Qué hace |
| ---- | ---- | -------- |
| `reto-03-listas` | 03 | Lista enlazada (reproductor) y lista doble (historial del navegador) |
| `reto-04-pila-libros` | 04 | Pila de libros con formulario |
| `reto-05-cola-cajero` | 05 | Cola del cajero ordenada por fecha de llegada |
| `reto-08-arbol-binario` | 08 | Árbol binario: inorder, preorder, postorder, búsqueda y dibujo |
| `reto-09-arbol-nario` | 09 | Menú lateral construido desde un árbol N-ario |
| `reto-10-grafos` | 10 | Grafo de amigos y ciudades |
| `reto-11-trie-heap` | 11 | Buscador por prefijo (Trie) con top K (Heap) |

## Ejecutar

```bash
flutter pub get
flutter run
```

La pantalla de inicio lista los retos; cada uno abre su página. Los recorridos
y estructuras también se imprimen en la consola (pestaña Run).
